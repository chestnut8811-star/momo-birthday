# ももちゃんの おたんじょうび（iPhone 向け Web アプリ）

4さいの誕生日をお祝いする、雪の王国の Web アプリです。iPhone の Safari、またはホーム画面に追加して全画面で使います。

## できること

| 場面 | 内容 |
|------|------|
| タイトル | 氷でできた大きな「4」とティアラ、名前、雪のお城。どこを触ってもキラキラ |
| ケーキ | ロウソクが1本ずつ灯る → オルゴールのハッピーバースデー → iPhone に「ふーっ」と息を吹くと炎が揺れて消える → 暗転して紙吹雪と「おめでとう！」 |
| 思い出 | 写真が1枚ずつ降ってくる。凍っているので指でこすると氷が溶けて見える（触らなくても4.5秒で自動で溶ける） |
| フィナーレ | 写真がハート形（5枚以下は扇形）に集まり、家族からのメッセージカード |
| 設定（おうちのかた用） | タイトル画面右上の ⚙ を**長押し**。名前・年齢（ロウソクの本数）・写真・メッセージ・消えやすさ・音と声 |

- 息が弱くても、かざぐるま・炎の傾き・舞い上がる雪で反応が見えます。マイクが使えないときは炎をタッチして消せます。
- 子どもの誤操作よけに、画面の隅の ⌂（さいしょにもどる）と 🔈（音）は**長押し**で反応します。短く押すと案内が出ます。🔈 は音楽・効果音・声をまとめて消します。
- 案内役の雪だるまは、吹き出しと **VOICEVOX（ずんだもん）の声** で話します（設定でオフにできます）。名前・年齢入りのせりふは「ももちゃん・4さい」で作ってあり、設定で名前や年齢を変えたときは名前の入らない言い方に切り替わります。

## iPhone で使うまで

マイクは **https のページでしか使えない**ため、インターネット上に置く必要があります（おすすめは GitHub Pages）。公開されるのはアプリ本体だけで、写真や名前の設定は含まれません。

1. 公開した URL を iPhone の Safari で開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開く（全画面になります）
4. タイトル画面右上の ⚙ を長押し →「写真を選ぶ」で思い出の写真を選ぶ（何枚でも。ひとことコメントと並べ替えもできます）
5. 「はじめる」→ 歌のあと、マイクの使用を「許可」

> **注意**: Safari とホーム画面のアプリは保存場所が別です。写真は、実際に使う方（ホーム画面のアプリ）で選んでください。
>
> アプリを更新したときは、ホーム画面のアプリを開くと裏で新しい版が届き、タイトル画面で自動的に読み込み直されます。当日の前に一度開いて、タイトル画面まで戻しておくと安心です。

### 当日のコツ

- 「ロウソクの消えやすさ」は **やさしい** がおすすめ。設定の「マイクを試す」で、吹いたときにメーターが紫の線を越えるか確かめておくと安心です。
- iPhone の**下側（マイク）**を、ももちゃんの口から 20〜30cm くらいに向けて持つと消えやすくなります。
- 音が出ないときは、音量と消音モードを確認してください。
- 子どもがアプリの外に出てしまうのを防ぐには、iPhone の「アクセスガイド」（設定 → アクセシビリティ → アクセスガイド）が便利です。

## プライバシーと著作権

- 写真・名前・メッセージは、その iPhone の中（IndexedDB / localStorage）にだけ保存され、どこにも送信されません。外部のフォントや解析タグも読み込みません。
- 絵はすべてコードで描いたオリジナルです（雪の結晶・お城・雪だるま・ティアラ・ケーキ・桃）。ディズニーのキャラクター画像や楽曲は使っていません。
- 曲はパブリックドメインの「Happy Birthday to You」「きらきら星」を、オルゴールの音色でその場で合成しています。
- 雪だるまの声は VOICEVOX で作成しました。クレジット: **VOICEVOX:ずんだもん**（タイトル画面の右下と設定画面に表示）。利用規約: https://zunko.jp/con_ongen_kiyaku.html

## Mac で試す

```bash
python3 tools/serve.py 8765 app
```

ブラウザで http://localhost:8765 を開きます（localhost ではマイクも使えます）。

- 公開（更新）: `app/sw.js` の `VERSION` を上げてコミットし、`bash tools/deploy.sh`
- `?debug&sim` を付けると、マイクの代わりに合成した「にせの息」を使えます。開発者ツールのコンソールで `bday.blow(0.15, 2)` を実行するとロウソクが消えます。
- `?debug` を付けると、画面の左下にエラーと操作の記録が出ます（iPhone で原因を調べるとき用）。

## 開発メモ

```
app/            公開するのはこのフォルダだけ（ビルド不要の HTML / CSS / ES Modules）
  js/logic/     DOM に依存しない計算（息の判定・配置・設定）→ tests/ でテスト
  js/art/       SVG の絵の部品とサンプル写真
  js/fx/        雪・キラキラ・紙吹雪・霜
  js/audio/     オルゴール音色と効果音、せりふの再生、マイク
  voice/        雪だるまのせりふ（VOICEVOX で生成した m4a と voice.json）
  js/scenes/    各場面
  sw.js         オフライン用（版ごとにまとめてキャッシュ）
tests/          node --test
tools/          開発用サーバー、アイコン生成、声の生成、公開スクリプト
docs/           要件定義書・設計書
```

- テスト: `node --test tests/*.test.js`
- アイコンの作り直し: `node tools/make-icons.mjs`（rsvg-convert が必要）
- 声の作り直し: VOICEVOX を起動して `python3 tools/make-voices.py`。声（話者）やせりふ、名前・年齢はスクリプト先頭で変えられます
- **更新して公開し直すときは `app/sw.js` の `VERSION` を上げてください。** 上げないと、ホーム画面のアプリが古い版を表示し続けます。
