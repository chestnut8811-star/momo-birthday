# 要件定義書: ももちゃんの おたんじょうび（iPhone 向け Web アプリ）

作成日: 2026-10-10

## 目的

4歳の誕生日を迎えるももちゃんのお祝いの場で、家族が iPhone を囲んで遊べる「魔法の時間」をつくる。
ケーキのロウソクを本当に息で吹き消せる体験と、思い出の写真が雪の魔法で現れる演出で、本人と家族を楽しませる。

## 利用者と利用環境

- 利用者: ももちゃん（4歳。ひらがなは読めない前提で、絵・音・声・タッチで操作できること）と、操作を手伝う家族
- 動作環境: iPhone の Safari、またはホーム画面に追加した Web アプリ（全画面）。縦向きが主、横向きでも崩れない
- 配布形態: 静的サイト（HTTPS 必須。マイクは HTTPS でしか使えない）。写真は端末の中だけに保存し、サーバーには送らない

## 機能要件

### 必須（これがないと完成と言えない）

- [ ] 誕生日ケーキにロウソク（年齢の本数）が灯り、マイクに息を吹きかけると炎が揺れて消える
- [ ] 息の強さが目に見える（炎が傾く・かざぐるまが回る・雪が舞う）。弱い息でも反応が返る
- [ ] マイクが使えない・許可されないときは、炎をタッチして消せる
- [ ] 全部消えたらお祝いの演出（紙吹雪・効果音・「おめでとう」）
- [ ] 思い出の写真が雪と氷の魔法で1枚ずつ現れる演出（凍った写真を指でこすると氷が溶けて見える。触らなくても自動で溶ける）
- [ ] 写真は家族が iPhone のフォトライブラリから選んで登録できる（並べ替え・ひとことコメント・削除）
- [ ] アナと雪の女王が好きな子に向けた、雪と氷の王国の世界観（オリジナルの絵で表現）
- [ ] 最後に家族からのメッセージカード
- [ ] iPhone で全画面・ノッチ回避・誤操作（ズーム・選択・長押しメニュー）防止
- [ ] 可愛さと見た目の良さ（パステル、立体感のある文字とボタン、オルゴールの音）

### あれば良い（今回のスコープから外してもよい）

- [x] ハッピーバースデーのオルゴール伴奏（歌ってからロウソクを吹く流れ）
- [x] 案内役の雪だるまが話す（吹き出し＋読み上げ音声。設定でオフ可）
- [x] 画面のどこを触ってもキラキラが出る
- [x] ホーム画面に追加してオフラインでも起動（Service Worker）
- [x] サンプル写真で演出を試せる
- [ ] 前面カメラでティアラを付けて撮影する「おひめさま変身」（今回は対象外）

## 非機能要件

- 性能: iPhone で 60fps に近い滑らかさ。重い CSS filter のアニメーションを避ける。写真は取り込み時に長辺 1600px へ縮小
- セキュリティ / プライバシー: 写真・名前・メッセージは端末内（IndexedDB / localStorage）だけに保存。外部通信なし（フォント・CDN・解析タグを使わない）
- 著作権: ディズニーのキャラクター画像・ロゴ・楽曲は使わない。曲はパブリックドメイン（Happy Birthday to You、きらきら星）を自前で合成
- その他: 4歳児向けの文言はひらがな中心。保護者向けの設定画面は通常の日本語

## 前提・制約（技術選定を含む）

- ビルド不要の素の HTML/CSS/JavaScript（ES Modules）。理由: 依存パッケージなしで長く動き、GitHub Pages 等にそのまま置ける。生成物と元ファイルの二重管理を避ける
- 絵は SVG と Canvas でコードから描く（画像素材の権利問題がなく、拡大しても綺麗）
- 音は Web Audio API で合成（音源ファイル不要）
- 文字は iPhone 標準の「ヒラギノ丸ゴ」。Web フォントを読み込まない（オフライン・外部通信ゼロのため）
- 公開先は GitHub Pages を想定（公開はユーザーの確認後に行う）。公開されるのはアプリ本体だけで、写真は含まれない
- 名前の初期値は「ももちゃん」、年齢の初期値は 4。設定画面で変更できる

## スコープ外（今回やらないこと）

- 写真のクラウド保存・家族間共有
- 動画の再生
- ディズニー公式キャラクターの描画

## 未確定事項

- お祝いの日付・家族構成は不明 → メッセージの差出人の初期値は「みんなより」とし、設定で変更できるようにした
- 公開方法（GitHub Pages で公開してよいか）は完成後にユーザーへ確認する
